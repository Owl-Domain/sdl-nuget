# SDL3.TTF.Native

This package contains the native binaries for
[SDL3_Image](https://wiki.libsdl.org/SDL3_ttf/FrontPage).

Currently supported platforms:
- Linux *(x64 and Arm64)*.
- Windows *(x64 and Arm64)*.

## Development

This package is automatically built and published using GitHub Actions from the
[owl-domain/sdl-nuget](https://github.com/owl-domain/sdl-nuget) repository.
